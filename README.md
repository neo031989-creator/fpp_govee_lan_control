# FPP Govee LAN Control (FPP 10)

Plugin skeleton for controlling compatible Govee lamps via the official local LAN UDP protocol on port 4003. Includes a simple FPP menu page, saved device configuration, FPP commands for playlists/command presets, and software-generated color effects.

## Important limitations
- Govee LAN Control must be enabled for each supported lamp in Govee Home.
- Device support varies by model. The local LAN protocol generally exposes power, brightness, color/white temperature and status query; it does not provide arbitrary built-in Govee app scenes. The plugin's effects are generated by sending a sequence of RGB colors.
- The PHP UI and command registration follow common FPP plugin conventions, but this package has not been installed/tested on a live FPP 10 player. Review/test on a backup before show use.
- `pluginInfo.json` URLs are placeholders. To install via FPP Plugin Manager, publish this directory to a Git repository and replace `yourname` with the real repository owner.

## Manual install
Copy this folder to `/home/fpp/media/plugins/fpp-govee-lan`, then run:
```sh
chmod +x /home/fpp/media/plugins/fpp-govee-lan/scripts/*.sh /home/fpp/media/plugins/fpp-govee-lan/scripts/*.py
```
Use the Govee LAN Control item in the FPP menu to configure device IP addresses and test commands. FPP Commands named `Govee LAN - Power`, `Govee LAN - Brightness`, `Govee LAN - RGB Color`, `Govee LAN - Color Effect`, and `Govee LAN - Stop Effect` are intended for playlists, scheduler, and command presets.

## Direct CLI examples
```sh
scripts/govee_lan.py 192.168.1.50 on
scripts/govee_lan.py 192.168.1.50 brightness 60
scripts/govee_lan.py 192.168.1.50 color 255 0 80
scripts/govee_lan.py 192.168.1.50 effect rainbow 5
scripts/govee_lan.py 192.168.1.50 stop-effect
```
